# Pawon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Panel Windows yang mengelola nginx + PHP (multi versi) + MariaDB + Cloudflare Tunnel; nambah site = subdomain live dalam detik.

**Architecture:** Satu binary Go (`pawon.exe`) berisi web UI embedded + supervisor proses (Job Object) + generator config nginx + client CF API. State satu file `pawon-data/pawon.json`. Tunnel remotely-managed — ingress diupdate via API, tanpa restart cloudflared.

**Tech Stack:** Go (stdlib + `golang.org/x/sys/windows` + `go-sql-driver/mysql`), HTML + vanilla JS + Tailwind (standalone CLI, build-time), nginx/PHP-NTS/MariaDB/cloudflared sebagai binary ter-download.

**Spec:** `docs/superpowers/specs/2026-09-04-pawon-design.md` — eksekutor WAJIB baca spec ini; plan berargumen dari spec.

## Global Constraints

- Go module `pawon`; dependensi hanya: stdlib, `golang.org/x/sys`, `go-sql-driver/mysql`. Tanpa framework web, tanpa npm/node.
- UI statis di-embed via `embed.FS`; Tailwind dikompile build-time jadi `web/static/app.css` (standalone CLI, tanpa CDN).
- Port: panel 7080 (bind `127.0.0.1`), nginx 80, MariaDB 3306, PHP pool port_base 9100 + 100×indeks versi, 4 instance per pool.
- State: `pawon-data/pawon.json`; logs semua di `pawon-data/logs/`; bins di `bin/`; default root site di `sites/`.
- Versi binary ter-pin di `internal/versions.go`.
- Nama CF tunnel: `"pawon"`; ingress service: `http://localhost:80`; CNAME target `{tunnel_id}.cfargotunnel.com`, `proxied: true`.
- Suffix lokal: `*.test` + baris hosts `127.0.0.1 <sub>.test`.
- Composer: subcommand whitelist `create-project, require, install, update, dump-autoload`.
- Reload nginx SELALU lewat `nginx -t` dulu; gagal → rollback config lama.
- TDD: test dulu, merah → hijau; commit per task, pesan commit konvensional.
- Windows-first: test jalan di Windows; path pakai `/` (nginx & PHP terima).

```go
package state

import (
    "crypto/rand"
    "encoding/hex"
    "encoding/json"
    "os"
    "path/filepath"
    "sync"
    "time"
)

type Config struct { /* sesuai Interfaces di atas — struct tag json */ }

var mu sync.Mutex // serialisasi Load/Save/Add/Remove seluruh proses

func Load(path string) (Config, error) {
    mu.Lock(); defer mu.Unlock()
    var c Config
    b, err := os.ReadFile(path)
    if os.IsNotExist(err) {
        return c, nil
    }
    if err != nil {
        return c, err
    }
    return c, json.Unmarshal(b, &c)
}

func (c *Config) Save(path string) error {
    mu.Lock(); defer mu.Unlock()
    b, err := json.MarshalIndent(c, "", "  ")
    if err != nil {
        return err
    }
    tmp := path + ".tmp"
    if err := os.MkdirAll(filepath.Dir(path), 0o755); err != nil {
        return err
    }
    if err := os.WriteFile(tmp, b, 0o644); err != nil {
        return err
    }
    return os.Rename(tmp, path)
}

func (c *Config) AddSite(s Site) {
    mu.Lock(); defer mu.Unlock()
    b := make([]byte, 4)
    rand.Read(b)
    s.ID = hex.EncodeToString(b)
    s.CreatedAt = time.Now().UTC()
    c.Sites = append(c.Sites, s)
}

func (c *Config) RemoveSite(id string) bool {
    mu.Lock(); defer mu.Unlock()
    for i, s := range c.Sites {
        if s.ID == id {
            c.Sites = append(c.Sites[:i], c.Sites[i+1:]...)
            return true
        }
    }
    return false
}

func (c *Config) Site(id string) (Site, bool) {
    mu.Lock(); defer mu.Unlock()
    for _, s := range c.Sites {
        if s.ID == id {
            return s, true
        }
    }
    return Site{}, false
}
```

//go:build windows
package proc

import "golang.org/x/sys/windows"

var job windows.Handle

func init() {
    h, err := windows.CreateJobObject(nil, nil)
    if err == nil {
        job = h
        info := windows.JOBOBJECT_EXTENDED_LIMIT_INFORMATION{
            BasicLimitInformation: windows.JOBOBJECT_BASIC_LIMIT_INFORMATION{
                LimitFlags: windows.JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE,
            },
        }
        windows.SetInformationJobObject(job, windows.JobObjectExtendedLimitInformation,
            uintptr(unsafe.Pointer(&info)), uint32(unsafe.Sizeof(info)))
    }
}

func assignToJob(p *os.Process) {
    if job != 0 {
        windows.AssignProcessToJobObject(job, windows.Handle(p.Sys().(windows.Handle)))
    }
}
